# Luxx Aparts v3: доработка блоков

v3 включает предыдущие этапы: многослойный первый экран, WebGL-фототур и обновлённую галерею. Ниже перечислены новые изменения именно третьего этапа.

## По блокам

| Блок | Доработка v3 |
|---|---|

| Номера и 3D-тур | Сохранён работающий механизм v2; к нему добавлен прямой пункт в навигации по главной. Новые комнаты и планировки не выдумывались. |

| Галерея | Сохранены функции v2; доработаны состояния кнопок разделов и элементов увеличения. |

## Ограничения и честность представления

- 3D-тур остается галереей реальных фотографий, а не точной моделью здания или съемкой 360°.
- Чек-лист перед приездом действует только в текущем интерфейсе. Он не создает, не сохраняет и не подтверждает бронь.
- Поиск и фильтры работают по содержимому проекта, без стороннего сервиса и без новых заявлений о гостинице.
- Общие компоненты локализованы для RU/EN. Английский блок отзывов не добавлялся, поскольку его не было в исходной главной.
- Ручная визуальная проверка в браузере не завершена: локальные адреса блокируются, а отдельная тестовая копия требует входа в Higgsfield. Настоящие скриншоты и Lighthouse-замеры не получены.

## Проверки

- TypeScript: успешно.
- Сборка: успешно.
- ESLint измененных исполняемых файлов: без ошибок и предупреждений после выноса функции поиска.
- Автотесты: 20 пройдено, 0 ошибок, 144 утверждения. Это SSR/структурные тесты и тесты поиска, не полноценные браузерные испытания.
- Локальные якоря главных RU/EN проверены по готовому HTML: отсутствующих целей нет.
- Файлы src/lib/site.ts, src/lib/site-en.ts, src/lib/booking-ru.ts, src/components/booking-form.tsx, src/lib/analytics.ts, src/lib/i18n.ts и vite.config.ts не изменены относительно исходного архива.
- Новых зависимостей или генераций медиа на третьем этапе не было.

## Запуск

```sh
bun install --frozen-lockfile
bun run dev
```

```sh
bun run typecheck
bun run test:design
bun run build
```

Полный архив v3 предназначен для отдельной копии проекта. Архив stage-3-changes содержит только изменения относительно полного архива v2; накладывать его на исходный проект без этапов 1 и 2 нельзя.

Основной домен не менялся. GitHub zapoinov13/luxx-guide-ai в рамках этого этапа не обновлялся: авторизация для записи не подтверждена.
