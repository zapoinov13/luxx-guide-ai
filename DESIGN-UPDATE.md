# Luxx Aparts: обновление дизайна

Актуальная версия: v3. Дополнительные изменения описаны в DESIGN-STAGE-2.md и DESIGN-STAGE-3.md; итоговые результаты проверок приведены в документе третьего этапа.

## Что изменено

### Первый экран
- Реальные фотографии ресепшена, двухместного номера и коворкинга собраны в многослойную композицию.
- Пружинный наклон композиции реагирует на мышь без перерисовки React на каждом движении.
- Поочередное появление фотографий и текста, глубина, тени и отдельная ссылка к выбору номера.
- Сохранены фирменная зелёная палитра и локальный Manrope. Изменены размеры, отступы и визуальная иерархия.
- Те же улучшения применены к русской и английской главной.

### Каталог и рум-тур
- Обновлены карточки выбора размещения, фоторамки, кнопки и блок характеристик.
- Добавлена отдельная декоративная иллюстрация серебряного ключа с зелёным брелоком. Это созданная для дизайна иллюстрация, не фотография имущества хостела.
- Вместо прежнего CSS-фототура реализован дополнительный WebGL-режим на Three.js: реальные фото размещены на объёмных стендах, камера плавно меняет положение, есть приближение и боковые ракурсы.
- Внутри тура: переключение «Номер / Общие зоны», «3D / Фото», миниатюры, стрелки, свайп, приближение и сброс к первому фото.
- Тур открывается в доступном Radix Dialog с Escape, удержанием фокуса и возвратом к кнопке.
- При ошибке WebGL или загрузки модуля включается обычный режим фотографий.

ВАЖНО: это 3D-галерея реальных фотографий. Это НЕ панорамы 360°, НЕ точная модель помещения и НЕ реконструкция планировки. Об этом прямо сказано в интерфейсе.

### Анимации и производительность
- Один общий слой анимации вместо двух конкурировавших механизмов появления секций.
- Появление разделов при попадании в область просмотра, реакции кнопок и карточек, тонкий индикатор чтения.
- Общая кнопка отключения анимаций; учитывается системное prefers-reduced-motion.
- На телефонах тур по умолчанию открывается в режиме «Фото», 3D включается отдельно.
- Тяжёлый 3D-модуль загружается при открытии соответствующего режима, не входит в начальную сцену страницы.
- Ограничена плотность пикселей WebGL, для 3D используются версии фото 800px.
- Рендер запускается по взаимодействию и прекращается после затухания движения; при скрытой вкладке не рисует кадры.
- При закрытии сцены освобождаются текстуры, материалы, геометрия, WebGL-контекст и обработчики событий.
- Родной скролл страницы сохранён, перехвата прокрутки нет.

## Что НЕ менялось

Содержимое следующих файлов совпадает с исходным архивом: src/lib/site.ts, src/lib/site-en.ts, src/lib/booking-ru.ts, src/components/booking-form.tsx, src/lib/analytics.ts, src/lib/i18n.ts, vite.config.ts.

То есть цены, формула бронирования, аналитические события, адреса страниц и настройки публикации не менялись. Проблемы бизнес-логики из предыдущего аудита намеренно не исправлялись в этом дизайнерском проходе.

## Проверки

- Исходная сборка до изменений: успешно.
- Сборка после добавления дизайна: успешно, пререндерены 32 маршрута (включая служебные ответы).
- ESLint для всех изменённых/новых исполняемых компонентов: успешно.
- В v2 проходят 12 автоматических тестов, 112 утверждений. Проверены SSR тура и галереи, локализация, наличие реальных фото и ресурсов, отложенная загрузка WebGL, состояния пустой коллекции, разметка управления и режимы снижения движения.
- Размер отдельного WebGL-модуля при проверенной сборке: примерно 123 КБ gzip. Он загружается отдельно.
- В версии v2 полная проверка TypeScript проходит. Исходные ошибки в src/components/ui/chart.tsx и src/components/ui/input-otp.tsx исправлены точечным использованием типов из соответствующих библиотек без изменения поведения компонентов.
- Браузерный просмотр локального сервера был заблокирован средой. Скриншоты, реальные мобильные замеры и ручная проверка WebGL в браузере не выполнялись. Автотесты не заменяют визуальную проверку. До обновления основного сайта проверить по чек-листу ниже.

## Как открыть и проверить

Работайте с отдельной копией, не заменяйте действующий сайт без просмотра.

```sh
bun install --frozen-lockfile
bun run dev
```

Адрес тестовой версии покажет команда запуска.

```sh
bun run test:design
bun run build
```

Публикация остаётся на прежней инфраструктуре проекта. Внешний домен автоматически не обновлялся.

## Чек-лист перед публикацией

1. Главная на ширинах 390, 768 и 1440px: отсутствие горизонтального переполнения, доступность кнопки бронирования, порядок фотографий.
2. Русская и английская главная: выбрать каждый тип размещения и открыть тур.
3. В туре проверить фото, 3D, общие зоны, приближение, стрелки, свайпы, Escape, Tab и возврат фокуса.
4. Закрыть и открыть тур несколько раз; проверить Safari/iOS и Chrome/Android отдельно.
5. При выключенных анимациях и системном reduced motion контент должен оставаться видимым, управление доступным.
6. Проверить работу формы после закрытия тура, мобильного меню и страницы с прямой ссылкой.
7. Измерить скорость/Lighthouse в опубликованном тестовом окружении. Реальные показатели производительности в этой среде не измерены.
